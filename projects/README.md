# 阶段项目

每个阶段都把新增知识并入同一个脱敏 CRM 领域。项目目录提供验收契约而非可复制的唯一答案；对应参考实现分散在每周 solutions 中。

1. `01-data-cli`：数据清洗与查询 CLI。
2. `02-node-http`：无框架 HTTP 服务。
3. `03-typescript-service`：strict TypeScript 重构。
4. `04-apaas-functions`：可测试云函数。
5. `05-react-dashboard`：客户界面与看板。
6. `06-nest-api`：分层 NestJS API。
7. `07-reliable-sync`：队列、Outbox 与观测。
8. `crm-capstone`：毕业项目。
