# 如何使用本书

这是一门课程，不是 API 字典。每一周都按“问题 → 模型 → 示例 → 反例 → CRM 源码 → 实验 → 测试 → 复盘”推进。只阅读不运行，不能算完成。

## 每周节奏

1. 用 2–3 小时阅读课程并手动预测示例输出。
2. 用 4–6 小时完成 `labs/week-XX`，不要先看答案。
3. 运行测试，根据失败信息定位问题。
4. 对照 `solutions/week-XX`，解释差异而非复制代码。
5. 用 1 小时阅读指定 CRM 源码，并画出数据流。
6. 完成本课自测；不能口述答案就回到对应小节。

## 仓库地图

```text
docs/                  教材与项目附录
labs/week-XX/          每周 starter 和测试
solutions/week-XX/     参考实现与解释
projects/              阶段项目和毕业项目
scripts/               结构、覆盖率与链接检查
```

## 何时算学会

学会一个知识点至少需要三种证据：能预测代码行为；能独立写出并通过测试；能在 CRM 项目中指出真实用途和风险。背诵定义不算。
