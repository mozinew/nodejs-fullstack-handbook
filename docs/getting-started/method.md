# 学习与验收方法

## Java 经验怎样复用

复用领域建模、分层、事务、测试和故障分析能力；暂时放下“所有抽象都从 class 开始”“async 等于新线程”“TypeScript 类型运行时仍存在”这三种假设。每课的 Java 对照会指出能迁移和不能迁移的部分。

## 怎样使用 AI

先独立写出预测，再让 AI 解释；先保留失败测试，再让 AI 提修复；最后关闭答案重新实现。禁止把真实 Token、Cookie、客户数据和生产日志原样交给 AI。
