# 版本兼容矩阵

| 能力 | 现代课程主线 | 当前 CRM 项目 | 学习策略 |
|---|---|---|---|
| Node.js | 24 LTS | 20；另有 14 遗留依赖目录 | 主课用 24，项目实验在 20 再验证 |
| React | 19 | 17 | 先学现代组件模型，标注并发/Strict Mode/挂载 API 差异 |
| TypeScript | 当前锁定稳定版、strict | 组件 5.5，云函数多为 JS | 新实验 strict；项目逐边界迁移 |
| 模块 | ESM 优先 | 云函数 CJS、Vite ESM/CJS 混合 | 必须同时掌握，禁止盲目改扩展名 |
| 测试 | Node test/Vitest/Jest | 项目缺少系统测试 | 纯函数先用 Node test，再按框架升级 |

兼容原则：运行时、类型声明、构建目标和平台沙箱分别验证。现代写法只有通过 Node 20 和 aPaaS 实际环境验证后，才能用于当前项目。
